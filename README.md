# DSRNet

Official repository for the paper:

**DSRNet: A Dual-Stream Residual Editing Network for RFI Mitigation on Spaceborne SAR Echoes**

DSRNet is a dual-stream framework for localized RFI mitigation on spaceborne SAR echoes. It performs gated complex residual editing to suppress interference while preserving unaffected time-frequency regions.

> The paper is currently under review.  
> The source code, pretrained models, and data preparation instructions will be released upon acceptance.
